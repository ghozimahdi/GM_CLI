Commands

Everything you run daily.

Run inside your Flutter project: gm [OPTIONS] [COMMAND]. Commands that touch modules let you pick one, several or all of them.

create project

New Flutter project with a Clean Architecture, modular structure.

create module

Add a data, domain or feature module for modularization.

build-b

Run build_runner for the modules you select.

get-g

flutter pub get for selected modules.

clear-c

flutter clean and remove pubspec.lock for selected modules.

app

Interactively build APK or IPA files.

route

Generate route files for your Flutter project.

flutter · dart

Pass-through commands such as pub add <package>.

info · help · donate

Prerequisites, usage and ways to support the project.

OptionWhat it does
-b --buildRun build_runner after module selection
-l --localizeGenerate easy_localization files
-a --assetsGenerate assets with flutter gen
-c --flutter_cleanFlutter clean for a single module
-g --flutter_getflutter pub get for a single module
--allbuild_runner, easy_localization and assets in one go
-V --versionPrint version information

Clean Architecture,
already wired.

Every feature lives in its own data, domain and presentation module, so the app stays scalable as it grows.

app/
packages/
  ├── library/
  │   └── library_common/
  ├── data/
  │   ├── data_common/
  │   ├── data_auth/
  │   └── data_analytic/
  │       ├── di/  config/  model/
  │       └── mapper/  repository/
  ├── domain/
  │   ├── domain_common/
  │   ├── domain_auth/
  │   └── domain_analytic/
  │       ├── di/  config/  model/
  │       └── use_case/  repository/
  └── presentation/
      ├── feature_common/
      ├── feature_dashboard/
      └── feature_auth/
          └── bloc/  config/  di/  page/

Library

Shared utilities, components and resources reused across modules.

Data

Data sources, models, mappers and repository implementations.

Domain

Business logic: use cases and repository interfaces per module.

Presentation

Features, pages and BLoC state management.

Install

Up and running in a minute.

Requires Flutter. Prebuilt macOS binaries ship with every release.

Homebrew

Recommended on macOS.

brew tap ghozimahdi/gm https://github.com/ghozimahdi/GM_CLI
brew install ghozimahdi/gm/gm
Use the full name ghozimahdi/gm/gm. A plain brew install gm installs GraphicsMagick.

Update

Pull the latest formula and upgrade.

brew update
brew upgrade ghozimahdi/gm/gm

Build from source

Requires Rust.

git clone https://github.com/ghozimahdi/GM_CLI.git
cd GM_CLI && cargo build --release
./target/release/gm help
